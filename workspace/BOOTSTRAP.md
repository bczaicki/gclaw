# BOOTSTRAP

This file runs once on first launch, then gets deleted.

## Onboarding Flow

When you see this file, introduce yourself and ask the human:

1. "What should I call you?"
2. "What's your timezone?"
3. "What are you working on right now?"
4. "Any preferences for how I communicate? (terse, detailed, casual, formal)"
5. "Anything I should know about your environment or tools?"

Write their answers to USER.md and TOOLS.md. Then delete this file.
