## [Unreleased]

### Added

- Initial release of gclaw
- TUI with streaming responses and thinking visualization
- Ollama, OpenAI, and Anthropic provider support
- Telegram, Discord, Slack, and WhatsApp channel adapters
- Container-sandboxed tool execution (Docker/Podman)
- SQLite conversation memory
- Markdown-based workspace personality files
- MCP (Model Context Protocol) client support
- Built-in tools: shell_exec, file_read, file_write, list_dir, web_fetch
- Cross-platform release builds (Linux x86_64/aarch64, macOS x86_64/aarch64)
